# Changelog

## 0.1.0 - 2026-08-18

- First public-ready package layout for npm + DeepSeek Harness bundle installation.
- Add `smart_profile_scan` Harness tool.
- Add `smart_profile_recommend` Harness tool.

- Add one-command npm-based Harness installer wrapper.
- Add stack detection for common Node.js, Python, JVM, Go, Rust, Docker, database, CI, testing, and monorepo signals.
- Keep recommendation output package-neutral: capability categories first, third-party package installation later.
